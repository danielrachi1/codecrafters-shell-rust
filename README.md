# Rust shell

[![progress-banner](https://backend.codecrafters.io/progress/shell/f94b2e34-2963-4a46-8840-3e7f898cc5a0)](https://app.codecrafters.io/users/codecrafters-bot?r=2qF)

This is my implementation of the [Codecrafters Shell Challenge](https://app.codecrafters.io/courses/shell/overview), in Rust. A POSIX compliant shell that's capable of interpreting shell commands, running external programs and builtin commands like cd, pwd, echo and more. You can see all features in the codecrafters website.

I tried to write all code by hand. But there were a few stages where I got stuck and used Claude Code. For transparency, I've included Claude as a co-author of the commits where I used its assistance.
